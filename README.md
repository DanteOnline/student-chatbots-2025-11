# Homework 9. Bot with langgraph

Бот - Генератор тупых советов.
Может общаться текстом и голосом.
В текстовом формате идет либо в словарь, либо отвечает напрямую

## Установка

```commandline
pip install -r requirements.txt
```

## Запуск

### Make

```commandline
make run
```

### Python

```commandline
python main.py
```

## Команды

- /start - главное меню
- /help - главное меню

## Ввод
<вопрос> - вопрос к LLM (текстом и голосом)
