# Homework 8. Bot with LLM and Voice mode

Бот - Генератор тупых советов.
Может общаться текстом и голосом

## Установка

```commandline
poetry install
```

## Запуск

### Make

```commandline
make run
```

### Python

```commandline
python main.py
```

## Команды

- /start - главное меню
- /help - главное меню
- /ask <вопрос> - вопрос к LLM
